# Startup Validator — Agent Prompt Reference

This file contains the detailed prompt templates used by each research agent.
The SKILL.md file references these prompts inline for simplicity, but they
can be extracted here if the prompts grow too large for the main file.

## Agent Types

1. **Reddit & Forum Mining Agent** — Searches Reddit, industry forums, YouTube, and app stores for pain signal evidence
2. **Competitor Mapping Agent** — Maps every competitor with pricing, features, funding, and threat level
3. **Pricing Strategy Agent** — Recommends specific tier pricing based on competitive landscape
4. **Differentiation Strategy Agent** — Identifies wedge features and positioning
5. **Trust & Adoption Agent** — Creates 90-day trust-building plan for skeptical audiences
6. **Go-to-Market Agent** — Ranks channels by CAC and audience size with budget scenarios
